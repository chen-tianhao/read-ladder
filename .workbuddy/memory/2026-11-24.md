## Read Ladder（阅读阶梯）— 从零建成

为阅读困难儿童做的分块阅读静态站，仓库 `E:\github_code\read-ladder`，远程
`github.com/chen-tianhao/read-ladder`。首次实现完成，`npm run build` 通过。

### 关键技术决定
- **零运行时依赖**：中文分词用浏览器内置 `Intl.Segmenter`（ICU 词典），
  未采用 jieba-wasm（4MB WASM）。实测两者在日常散文上碎片率相当
  （ICU 50%/47%/24% vs jieba 45%/59%/63%），4MB 体积不划算。
- **切块引擎**：分词 → 单元（词+后随标点）→ 三档聚合。层级与聚合解耦。
  - L1 长句块：中 6–12 字 / 英 4–6 词，遇逗号句号断开
  - L2 短语：中文只并虚词后缀（的/着/了）+ 句首单字可与后接双字词合并；
    英文 2–3 词，用功能词表避免块尾落在介词冠词上
  - L3 词：一词一块
- **中文分词修正**：`mergeSuffixSingles()` 用 `SUFFIX_CHARS` 缝合 ICU 拆开的
  「驶｜过」「河｜边」这类单字，属于分词层修正，对三档同时生效。
- **TTS**：Web Speech API，按句切分队列规避 Chrome 15 秒截断，
  `voiceschanged` 处理异步语音列表，iOS 首次手势 `unlock()`。
- **PDF**：打印样式表 + `window.print()`。已验证生成的 PDF 内含五种色块
  填充值与矢量文本（`print-color-adjust: exact` 生效）。
- **部署**：Vite 静态构建，产物 23KB JS + 9KB CSS（gzip 21KB）。
  Cloudflare Pages 需设 `NODE_VERSION=22`（Vite 8 要求 Node ≥20.19）。

### 已知取舍
中文 L2 与 L3 差异只有 10–20%，因为汉语词短且无空格。试过固定 4 字意群，
会切出「驶过宽阔的」这类错误边界，收益不抵风险，遂放弃。

### 无头验证方法（可复用）
Windows 上可用 `chrome --headless=new --screenshot --window-size=W,H` 截图；
但窗口宽度低于约 500px 会被 Chrome 最小窗口宽度截断，测移动端要在页面里
嵌 390px iframe 再截图。`--hide-scrollbars` 会导致 `<dialog>` 顶层不渲染。
